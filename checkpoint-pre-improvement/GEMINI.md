# Gemini 개발 작업 지침

이 저장소는 성수동이팀장 픽셀 오피스의 공개 시연 개발본이다. Gemini의 역할은 앱 안의 AI 직원이 아니라 디자인·개발 보조다.

## 먼저 확인

README.md, QA.md, index.html, art.js, core.js, app.js를 읽는다. assets/static-world-preview.png와 종별 atlas PNG를 실제로 확인한다. 기본 기능은 검사를 통과했지만 현재 픽셀 미술은 더 개선해야 한다.

## 첫 작업은 작게

대표 캐릭터와 대표 책상 한 구역의 시각 품질 개선안을 먼저 만든다. 전체 앱·방·업무 구조를 새로 만들지 않는다. 대표의 세이지색 개구리, 검정 뿔테, 코발트 스카프, 작은 황동 핀을 유지한다. 따뜻한 아이보리 벽·밝은 오크·더스티 블루·넓은 중앙 공간을 유지한다. 캐릭터 실루엣·정확한 픽셀 클러스터·소재별 명암·가구 비율을 개선한다. 큰 사각형이나 부유하는 이미지로 완성한 척하지 않는다.

개선 전후를 비교할 수 있는 실제 자산과 변경 목록을 제출한다. 프레임 수·완료 방향·미완성 상태를 정직하게 표시한다. 한 구역 검수 후 다른 구역으로 확대한다.

## 반드시 보존

- 고정 다섯 생물과 직원 역할·고유 ID.
- 1024×576, 16:9, 정수 픽셀, nearest-neighbor.
- 가구 충돌과 경로, 책상 후경/캐릭터/전경 가림, 접지점.
- 원본 기록과 시연 상태·화면 동작의 분리, 로컬 저장 키.
- core.js·legacy-data.js·app.js의 업무/저장 로직은 첫 시각 개선 범위에서 바꾸지 않는다.
- 실제 AI 실행·자동 중계·사업 승인·고객 발행으로 표현하지 않는다.

API 키 생성·추출·사용, Gemini API 호출 추가, 결제·외부 배포·저장소 강제 덮어쓰기는 하지 않는다. 공개 시연 데이터 외의 자료가 존재한다고 가정하지 않는다. 다른 AI와 자동 연결되었다고 주장하지 않는다.

## 검증

node test-core.cjs의 45개 검사를 유지한다. 브라우저 기능 시험은 QA.md의 범위와 한계를 구분한다. 기능 통과를 미술 품질 승인으로 간주하지 않는다. 변경 파일·자산 출처·검사 결과·미완료를 함께 보고한다.

## 연결 상태

이 파일을 GitHub에 추가한 것만으로 Google AI Studio와 연결된 것은 아니다. 사용자가 Google AI Studio에서 이 기존 저장소를 가져오고 필요한 계정 연결을 승인한 뒤에 실제 연동 여부를 확인해야 한다.

## 디자인 QA를 반영한 첫 제출 기준

승인 콘셉트는 질감·비율·실루엣이 살아 있는 시각 자료이고 현재 art.js는 로직 시험용 간이 프로그래머 아트다. 단순 도형을 더 늘리거나 전체 앱을 재생성해서 해결하지 않는다.

1. 대표를 세이지 숲개구리 모델로 실제 다시 그린 64×64 투명 PNG와 최소 idle/working/review 포즈부터 제안한다. 기존 데이터 ID bullfrog는 호환용으로 보존하지만 황소개구리와 동일한 네모난 골격을 강제하지 않는다. 큰 검정 뿔테·코발트 실크 스카프 매듭·작은 황동 핀이 읽혀야 한다.
2. 대표 책상만 후경·상판/본체·전면 가림 자산으로 분리한다. 공통 바닥 피벗, 광원, 3/4 원근을 맞추고 좌석에서 캐릭터 몸이 과하게 사라지지 않게 한다.
3. 실자산 PNG+JSON(state,direction,frame,duration,pivot,occlusionGroup)을 제출한다. 생성 이미지는 초안이며 전문 픽셀 정리·프레임 일관성 검수 전 완성 자산으로 부르지 않는다.
4. 기존 OfficeArt.sprite()/furniture() 인터페이스와 이동·충돌·시연 상태·저장 로직을 유지한다. 첫 단계에서는 가구 위치나 core.js 충돌 맵을 바꾸지 않는다.
5. 개선 전후 한 구역만 나란히 보여 주고, 적용 전 이팀장 검수를 요청한다. 나머지 네 캐릭터와 방 전체 확장은 이 시험의 비율·가림·모바일 판독성 확인 뒤에 진행한다.

참조 원안 이미지가 작업 환경에 실제로 없다면 공개 저장소의 간이 미리보기만으로 원안과 일치한다고 주장하지 않는다. 필요한 원안 접근을 먼저 확인한다.
